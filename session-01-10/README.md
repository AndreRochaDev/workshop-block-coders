# Session 01-10 — Unlock for Coders

A 4-hour hands-on workshop: modern software development with **GitHub Copilot** in VS Code. You'll build a .NET 10 library loans API and a React web UI **from scratch**, on your own machine.

## Before the day

Read [setup-check.md](setup-check.md) and run the checks. It takes about 10 minutes, and it's the difference between spending the afternoon building and spending it installing.

## On the day

Start in an empty folder and pull the requirements in:

```sh
curl -O https://raw.githubusercontent.com/AndreRochaDev/workshop-block-coders/main/session-01-10/library-requirements.md
```

Then point Copilot at it with `#file:library-requirements.md`.

| File | What it is |
|---|---|
| [library-requirements.md](library-requirements.md) | What you're building, iteration by iteration. Behaviour only — the structure is your call. |
| [setup-check.md](setup-check.md) | What to install and how to check it works |
| [framework-card.html](framework-card.html) | One-page takeaway: the workflow, the prompts, the review checklist. Open it in a browser and print it. |

Your repo will not look like your neighbour's. That's expected: the spec is the contract, not the file names.
