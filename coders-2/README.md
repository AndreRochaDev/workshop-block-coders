# Coders 2 · GitHub Copilot in VS Code

Materials for the workshop on Monday, 26 October 2026.

## Round 1: just build it

1. Create an empty folder called `timesheet-1` and open it in VS Code: **File → Open Folder**.
2. Open the Chat view (Ctrl+Alt+I, or ⌃⌘I on macOS) and pick **Agent** in the dropdown under the chat box.
3. Send this:

   ```text
   Download https://raw.githubusercontent.com/AndreRochaDev/workshop-block-coders/main/coders-2/requirements.md into this folder.
   ```

4. Read [requirements.md](requirements.md), then build the app with Copilot, any way you like. You have 30 minutes.

When time is up, you'll answer two questions about your app:

- How many hours did the pay cycle that just closed require?
- How does your app work that out?

Round 2 appears in this folder after the break.
